# AI-Driven LINE OA Module (Plug & Play)

โมดูลสำเร็จรูปสำหรับเชื่อมต่อ AI เข้ากับ LINE Official Account (LINE OA) ออกแบบตามสถาปัตยกรรมแบบ Decoupled และ Modular Design เพื่อให้นำไป 'เสียบใช้งาน' (Plug & Play) กับโปรเจกต์ธุรกิจต่างๆ ได้ทันที

## โครงสร้างโปรเจกต์ (Folder Structure)

- src/index.ts
- src/core/types.ts
- src/core/state-manager.ts
- src/adapters/ai-engine.ts
- src/handlers/webhook-handler.ts
