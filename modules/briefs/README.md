# Module Hub — Briefs Directory

This directory preserves implementation briefs and dependency-planning inputs used while Module Hub was being built.

## Current vs historical

Current governance:
- `00-common-rules.md`
- `99-dependency-map-and-sequence.md`

Historical implementation inputs:
- all other `*.md` files in this directory

Historical briefs may contain original Planned/Stage labels, earlier assumptions, or implementation sequencing. They are retained as evidence and design history, not as current module status.

For current truth use:
1. `../REGISTRY.md` for registered module/version/maturity
2. `../ROADMAP.md` for current portfolio-level module map
3. `../../INDEX.md` for consumer catalog and copy rules
4. `../<module>/MODULE.md` and `../<module>/DESIGN.md` for current contract/boundaries
5. live source/tests when documentation and implementation disagree

Do not update a historical brief merely to make old chronology look current. Correct current authority documents instead.
